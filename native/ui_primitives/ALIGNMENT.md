# Product alignment

The web reference reviewed at repository revision `21e295e5ae` supplies the
comparison for NodeTool's compact working hierarchy, semantic text and color
roles, familiar input patterns, and focus on the active work. This native specification is authored
independently of other clients. Its module has no web build or token input.

Native action colors differ from the prior timeline palette so white labels on
primary and hover fills meet the measured 4.5:1 target in both schemes. Native
focus and control borders target 3:1 against their adjacent surfaces. The
native module uses Qt Quick controls and platform font fallback, so behavior and
rendering are verified in native hosts rather than assumed from another client.
The reviewed migration baseline and decisions are in [the plan](PLAN.md).
