This namespace contains 5 node(s).

## Available Nodes

- **[Add Blend](addblend.md)** - Additive composite of two images: out = source + over × gain.
- **[Color Overlay](coloroverlay.md)** - Tint an image with a constant colour while preserving source coverage.
- **[Drop Shadow](dropshadow.md)** - Cast a soft drop shadow behind the source silhouette.
- **[Glow](glow.md)** - Bloom / glow effect: bright-pass + blur + additive composite over source.
- **[Outline](outline.md)** - Draw a flat outline / stroke around the source silhouette.
