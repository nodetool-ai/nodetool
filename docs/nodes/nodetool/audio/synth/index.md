This namespace contains 9 node(s).

## Available Nodes

- **[ADSR](adsr.md)** - ADSR envelope generator driven by a gate CV stream.
- **[Attenuverter](attenuverter.md)** - Scales and offsets a CV (or audio) stream: out = in * scale + offset.
- **[Gate](gate.md)** - Generates a repeating on/off gate CV pattern — the patch's master clock.
- **[LFO](lfo.md)** - Low-frequency oscillator emitting a control-voltage stream.
- **[Mixer](mixer.md)** - Sums up to four audio streams with per-input levels.
- **[Oscillator](oscillator.md)** - Voltage-controlled oscillator generating sine, saw, square, triangle or noise...
- **[Sample & Hold](samplehold.md)** - Samples the signal input on each trigger rising edge and holds it.
- **[VCA](vca.md)** - Voltage-controlled amplifier: multiplies an audio stream by a CV stream.
- **[VCF](vcf.md)** - Voltage-controlled filter: a biquad whose cutoff is modulated by a CV stream.
