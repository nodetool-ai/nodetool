**Type:** `nodetool.input.DocumentInput`

## Description

Accepts an editable Markdown document or converts .txt, .html, .docx, or .pdf input files to Markdown, outputting both the document reference and its Markdown text.
    input, parameter, document, markdown, text, pdf, docx, html, reference
