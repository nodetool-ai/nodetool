Stable target exposure is narrow and semantic: chat messages, tool calls, editor controls, document regions, timeline regions, clip ids, and test results use `data-focus-id`. Group shots resolve every member before framing. Chat and assistant docks scroll deterministically at the shot anchor before measurement, including on backward seeks.

Code shots measure the intrinsic text in the production editor's read-only fallback. This removes lazy editor loading and caret motion from the replay. The saved CSV fixtures are checked with Papa Parse: clean input produces 7.5, the original edge case produces NaN, and the repaired sum produces 3. Test reports remain timed synthetic cast events.

T8 starts from a submitted message rather than simulated typing. Every authored action beat maps to an existing chat, document patch, test report, timeline, zoom, or playback event. The catalog test also pins T9’s nonlinear presentation times to its six cast events.
