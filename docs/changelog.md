NodeTool publishes its changes in two places.

| Where | What it holds |
|-------|---------------|
| [CHANGELOG.md](https://github.com/nodetool-ai/nodetool/blob/main/CHANGELOG.md) | One section per month, grouped into Added, Changed, and Removed, then by area (UI, agents, nodes, runtime) |
| [GitHub releases](https://github.com/nodetool-ai/nodetool/releases) | Tagged releases with the desktop installers. A tag such as `v0.7.0` also produces a Docker image tag of the same version |

The changelog follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) and [Semantic Versioning](https://semver.org/spec/v2.0.0.html). The repository's own note says the log is generated by Claude using a script, so check the commit history when you need an exact detail.

Desktop releases come in two channels, **Stable** and **Nightly**. The channel is a setting in the desktop app. See [Upgrading](upgrading.md) for how to pick one and how to update.

## Last three months

This is a summary, not the full list. The monthly sections below name the main additions and changes.

### September 2026

Shipped as [v0.7.0](https://github.com/nodetool-ai/nodetool/releases/tag/v0.7.0).

- **Guided creation.** Guided flows start workflow, script, storyboard, timeline, and game documents.
- **Games.** A game flow exports a Godot project.
- **Projects and chat.** A project picker sits above the workspace tabs, with entities assigned to projects. A project can hold several chat threads, and memory has its own page outside chat.
- **Storyboards.** Each storyboard card has a shot editor, and reference-to-video works in chat, providers, and storyboard render.
- **Timeline.** MIDI tracks with a piano roll, 3D clips, clip crop, film grain, audio-driven motion, subject mattes, speech and music generation in the composer, and zip import and export.
- **Models.** GPT Image 2.5, Flux 3 Video Edit, and new FAL, KIE, and AtlasCloud models. Video upscale, interpolate, and outpaint task types.
- **Runtime.** External MCP servers join the agent toolbelt. Generations recover after a reload or a browser disconnect.
- **Changed.** Left-panel navigation was consolidated, the setup and connect model pickers were redesigned, and the chat model is stored per conversation.
- **Removed.** The `lib.apple` node library.

### August 2026

- **Projects.** Projects became the workspace unit, and a new-project surface starts from a brief or a skill.
- **Apps.** Mini apps deploy to a hidden URL without login. App Builder gained form, capture, compare, pick, and Sketch Pad widgets.
- **Editors.** SVG became its own document. Sketch gained a Deform transform, and agents can place images on sketch layers. The timeline and sketch editors show cost estimates before a render.
- **Agents.** Immutable system skills, plan mode with a real planner, a live browser capability, web search through OpenAI and Gemini, and audio and video measurement tools.
- **Runtime.** QuickJS sandbox compiler and packs, 60 more AtlasCloud image and video models, and timeline JavaScript for custom clip animations.
- **Added.** A Chrome extension and a Telegram package.
- **Changed.** The dashboard was removed and onboarding moved into the new-project surface. Storyboard was restyled as a shot grid. 24 nodes already covered by the sandbox and Code node were retired.

### July 2026

- **Script editor.** Author, voice, timeline bridge, SRT and VTT export, and agent tools.
- **Storyboards.** A storyboard surface with a still and clip gallery, a render queue, and an assistant panel. Entities work in `@` mentions and storyboard shots.
- **Code node.** AI authoring with typed handles.
- **Mini apps.** Sketch, Timeline, chat, AI, and the remaining Puck widget types.
- **Agents and CLI.** Thread-level memory, tool-loop evals for editor surfaces, Google Workspace tools, Claude subscription login for the Claude Agent provider, and local database reads, RAG collections, and cost tracking in the `nodetool` CLI.
- **Runtime.** An in-process `node-llama-cpp` provider with native function calling, 327 FAL models and 82 Replicate models, nightly price catalog sync, and Flatpak as a Linux release target.

For earlier months, read [CHANGELOG.md](https://github.com/nodetool-ai/nodetool/blob/main/CHANGELOG.md).
