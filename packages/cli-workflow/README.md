# Workflow commands

Extended workflow execution, authored JavaScript/TypeScript workflows, debugging,
node tools and workflow resource operations. JSON execution also remains in the
default CLI.

Install this independent command feature through the default CLI:

```bash
nodetool packs add cli-workflow --yes
nodetool debug --help
```

Commands do not install missing features automatically. See the
[command reference](../../docs/cli.md#install-command-features).
