# @nodetool-ai/godot-templates

Three hand-written Godot 4.3 projects (`templates/platformer`, `templates/topdown`,
`templates/shmup`), each with a `manifest.json` that conforms to
`gameAssetManifest` from `@nodetool-ai/protocol`, and a small headless runner.

Asset paths are the contract with the Godot writer. A slot id maps to a file by
replacing `.` with `_`:

| kind | path |
|---|---|
| spritesheet | `assets/sprites/<id>.tres` (+ `.png`) |
| tileset | `assets/tiles/<id>.tres` (+ `.png`) |
| image | `assets/images/<id>.png` |
| sfx, music | `assets/audio/<id>.wav` |

Placeholders at those paths are generated by `node scripts/make-placeholders.mjs`
and checked in, so every template runs before a single asset is generated.

```ts
import { listTemplates, importProject, checkScripts, smokeProject } from "@nodetool-ai/godot-templates";
```

`findGodot()` reads `GODOT_BIN`, then looks up `godot`, `godot4`, `Godot` on `PATH`.
Every runner throws `GodotMissingError` when no binary is found.
Smoke: `godot --headless --path <dir> -s res://test/smoke.gd`.
