# Phase boundaries

Continue in the current session while its context supports the next step.
Compaction does not end the task. Preserve the objective, decisions,
authorization, evidence, changed artifacts, and remaining work when resuming.

Use the host's available context controls when needed. Do not assume `/clear`,
`/compact`, or a handoff skill exists, or rely on a fixed token threshold.
Clear context only when preceding work is irrelevant to the next task.

When work must move to another directory, harness, or person, prepare a handoff
with file paths, decisions, verification results, and the next action. Sending
it to another person requires the user's authorization.

When delegation is available and permitted, use a subagent for an independent,
bounded task while useful work continues locally. Give it the necessary source
artifacts and constraints. Integrate its evidence before claiming completion.
