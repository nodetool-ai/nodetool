# NodeTool

NodeTool is an AI video editor with an agent that helps you create and edit. Work in the timeline, or connect nodes to build reusable workflows. Create images, audio, storyboards and 3D scenes alongside your video. Connect supported provider accounts or run supported models locally. Studio saves projects on your computer. Developers can use the API, command line or MCP to connect other tools.

## Editions

- [NodeTool Studio](https://nodetool.ai/studio.md) is the free, open-source desktop application for macOS, Windows, and Linux. Connect a supported provider account or run supported models locally. Provider charges may apply.
- [NodeTool Cloud](https://nodetool.ai/cloud.md) is the hosted browser application, currently in alpha.
