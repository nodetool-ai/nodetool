# NodeTool, the Open-Source Creative Harness

NodeTool is an open-source creative harness: the tools, editors, models, keys, and run record an AI agent works inside. NodeTool agents can operate editable workflows, apps, and projects through tools exposed by its editors. You can inspect tool calls, results, errors, and interventions, then revise and reuse the workflow. Compatible external agents can use the tools over MCP.

Read the [agent documentation](https://docs.nodetool.ai/agents/index.md) for installation, schema discovery, validation, execution, and job monitoring.
