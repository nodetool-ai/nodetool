# CC0 Impact drum one-shots — provenance and license

These twenty raw one-shots form DR-1's `CC0 IMPACT` and `CC0 BOUNCE`
factory-sample banks. They play in the `oscB` sample layer in both the web
worklet and JUCE processor.

- **Upstream:** https://github.com/Boochi44/free-drum-samples
- **Upstream revision:** `77ba31428a079dd8f17c8e144c1e649ea0a198b3`, downloaded 2026-09-20.
- **License declared by upstream:** Creative Commons CC0 1.0 Universal.
- **Original upstream kit:** `drum-samples/01-hard-trap/`.

The upstream README explicitly places all repository samples under CC0 1.0,
allows commercial redistribution, and identifies the TR-808 CC0 source used
for its derived one-shots. No attribution is required; this record is kept so
the factory bank remains auditable.
